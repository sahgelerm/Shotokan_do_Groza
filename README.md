Shotokan_do_Groza

Создание ИИ-системы по оценке исполнения ката шотокан карате-до.

Этапы стажировки:
- Этап 1: https://ai-hunter.ru/groza1  
- Этап 2: https://ai-hunter.ru/groza2  

Описание проекта

Проект выполнен в рамках стажировки Shotokan_do_Groza в процессе двух этапов и посвящён классификации стоек карате с использованием методов компьютерного зрения и глубокого обучения.

Задача

Построить модель, способную классифицировать стойки и техники карате на основе изображений.

Мой вклад

Этап 1 — Подготовка данных и 3D-анализ
- Разметка видеозаписей по техникам ката  
- Формирование датасета из отдельных приемов  
- Исследование фреймворка EasyMocap для захвата движений человека  
- Работа с 3D-ключевыми точками тела
- Документирование результатов и подготовка материалов  
- Участие в обсуждении технического задания и развитии проекта    

Этап 2 — Модели и улучшение решения
- Участие в разметке видеоматериала  
- Подготовка датасета для обучения моделей  
- Разработка моделей сверточных нейронных сетей (CNN)  
- Обучение и оптимизация модели классификации стоек карате  
- Содействие в интеграции модели в общий пайплайн  
- Подготовка презентации проекта  

Pipeline решения

Датасет (изображения) → Предобработка → CNN → Классификация

Используемые технологии
- Python  
- OpenCV  
- CNN
- TensorFlow (если использовали — оставь нужное)  
- NumPy
- Pandas
  
Данные

- Датасет состоит из изображений, разбитых по классам (каждая папка — отдельная стойка)
- Количество классов определяется автоматически
- Данные загружаются и распаковываются из архива.

Особенности:

- структура: `class_name/image.jpg`
- используется балансировка через равномерную загрузку классов.

Предобработка данных

- Изображения приводятся к единому размеру:
  - **128x64**
- Нормализация и преобразование в тензоры
- Формирование:
  - `x_data` — изображения  
  - `y_data` — метки классов  

Архитектура модели

Используется сверточная нейронная сеть (CNN) с глубокой архитектурой:

Основные компоненты:

- Conv2D слои (до 1024 фильтров)
- MaxPooling
- BatchNormalization
- Fully Connected (Dense) слои

Особенности:

- Глубокая архитектура (6 сверточных блоков)
- Увеличение количества фильтров по мере углубления
- Использование BatchNorm для стабилизации обучения.

Архитектура (упрощённо)

Input (64x128x3)
↓
Conv → Conv → Pool
↓
Conv → BatchNorm → Pool
↓
Conv → Pool
↓
Conv (512)
↓
Conv (1024)
↓
Flatten
↓
Dense (2048)
↓
Output (классы)
